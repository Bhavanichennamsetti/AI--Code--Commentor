# AI Code Commentor

AI Code Commentor is an AI-powered web application that helps developers understand, analyze, comment, explain, and debug code.

It also provides a Technical Screening Round where users can practice programming questions.

## Features

- AI Code Commenting
- Code Analysis
- Code Explanation
- Bug Fixing
- Code Download
- Multiple Programming Languages
- Technical Screening
- Easy, Medium and Hard Questions
- Practice Questions
- AI Code Evaluation
- Dark and Light Mode
- Responsive Design

## Technical Screening

### Easy
Focus: If / Else

5 main questions and 2 practice questions for each.

### Medium
Focus: Loops

5 main questions and 2 practice questions for each.

### Hard
Focus: Functions

5 main questions and 2 practice questions for each.

Total:

45 questions.
